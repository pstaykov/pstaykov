## Projects

### [Transformer from Scratch](https://github.com/pstaykov/transformer)
Decoder-only, LLaMA-style language model with a hand-written forward and backward pass, implemented in parallel NumPy (CPU) (and CUDA/cuBLAS (GPU) versions). Includes pretraining on FineWeb, supervised fine-tuning for chat, and simulated FP8 training. Base and chat checkpoints published on HuggingFace.


### [ML from Scratch](https://github.com/pstaykov/MLfromScratch)
Implementations of classic machine learning algorithms in Python and C, without external ML libraries: linear regression, k-NN, k-means, CART, gradient boosting, random forests, and neural networks with hand-written gradient descent. Each algorithm is paired with a written explanation.
